How this site is built:

- **Jekyll** static site generator, based on the
  [digital-garden-jekyll-template](https://github.com/maximevaillancourt/digital-garden-jekyll-template)
  (MIT) by Maxime Vaillancourt.
- **Colors:** the [Flexoki](https://github.com/kepano/flexoki) palette (MIT),
  with a light/dark toggle.
- **Hosting:** GitHub Pages, built via GitHub Actions.

Notes can link to each other with double-bracket syntax while writing, but the
site itself is kept intentionally simple.

See also [[welcome]] and [[now]].
